# 동물 친구 30종 — 검토용 시안

사용자 요청으로 기존 10종에 20종을 더한 캐릭터 탐색안이다. 그림체 선택 답변은 아직 없으므로 몽그리와 어울리는 인형풍을 작업 가정으로 사용했다. 이름과 종의 정본은 roster.json이다. 이미지 속 한글의 작은 형태 차이는 정본 목록을 따른다.

이미지는 내장 ImageGen으로 제작한 전체 비교용 시트이며, 개별 투명 에셋이나 실제 선택 화면 구현이 아니다. 기존 앱의 동물 ID·학생 프로필·입장 기능은 수정하지 않았다. 실제 화면에서는 모바일에 30개를 한꺼번에 작게 축소하지 말고 큰 선택 영역을 유지한 채 스크롤하도록 구성하는 것을 제안한다.

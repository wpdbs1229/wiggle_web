# Claude 전달용 — 참여 코드 뒤 「그림 자리」

기준 시안: [`reference/selected-art-desk.png`](reference/selected-art-desk.png), 1536×1024. **시안은 위치·분위기 참고용**이다. 화면 전체를 배경 이미지로 깔거나 그림·제목·날짜·버튼을 잘라서 재사용하지 않는다.

## 사용자가 확정한 흐름

1. 참여 코드를 입력한 뒤 저장된 그림이 **0장**이면 중간 화면 없이 바로 새 빈 도화지로 간다.
2. 저장된 그림이 **1장 이상**이면 이 「그림 자리」 화면을 보여 준다. 여기에는 **내 그림 목록 + 새 그림 그리기 + 이전에 만든 내 그림책 목록**이 한 화면에 함께 있다.
3. 그리던 그림은 목록에서 아이가 직접 「이어 그리기」를 고른다. 참여 코드 직후 자동으로 그리던 그림을 열지 않는다.

이 묶음은 **에셋과 구현 지시서**다. 앱 코드·API·운영 데이터·배포는 변경하지 않았다.

## 시안의 핵심 구조

- 머리: 기존 로고 왼쪽, 「수업 마치기」 오른쪽. 종료 동작은 현재 세션 해제 로직 재사용.
- 제목: `{student.nickname}의 그림 자리`. 시안의 「솔이」는 예시다. **학생 실명이나 고정 이름으로 쓰지 않는다.** 한 줄 안내도 짧게.
- 「내 그림」: 최근 그림 3장 정도와 **빈 도화지 모양의 「새 그림 그리기」 큰 카드**를 한 구역에 둔다. 그림이 많으면 「모두 보기」나 가로 목록으로 접근 가능하게 한다. 진행 중/완성 배지와 「이어 그리기」/「그림 보기」 행동을 분명히 구분한다.
- 「내 그림책」: 이전에 만든 책의 제목·쪽 수·상태를 보여 주고 책을 열 수 있게 한다. 그림책이 0권일 수 있으므로 이 **부분만** 짧은 빈 상태를 보여 준다. 책 목록 전체 보기 링크도 둔다.
- 실제 아이 그림·책 표지는 사용자 데이터다. 시안의 고양이·정원·비 그림과 두 책 표지는 **예시 데이터**다. PNG에서 잘라 기본 작품으로 배포하지 않는다. 책 미리보기 데이터가 없으면 제공된 빈 책 틀 + DOM 제목/상태를 사용하고, 임의의 아이 그림을 만들어 넣지 않는다.
- 기존 책은 단일 `SQUAREBOOK_HC`(243×248mm)로 확정됐다. 시안의 가로 책 장식보다 **실제 거의 정사각 표지 비율을 우선**한다. 두 책 틀 SVG는 248×248이다. 그림을 보여 줄 때 원래 비율 유지.

## 현재 코드와 연결 지점

| 현재 코드 | 확인한 역할 / 변경 시 유의점 |
| --- | --- |
| `app/components/JoinClient.tsx` | 코드 성공 뒤 `/student`로 이동 |
| `app/components/StudentEntry.tsx` | 현재는 `/api/student`를 받은 뒤 그리던 그림 또는 새 도화지로 **항상 자동 이동**. 위 확정 흐름으로 분기해야 함 |
| `app/api/student/route.ts` | `artworkTotal`, 최근 `artworks`, `student.nickname`을 제공. 0장 판정은 페이지 크기보다 총수 기준 |
| `app/components/Archive.tsx` | 기존 전체 그림 보관함/넘김 화면. 「내 그림 모두 보기」 연결에 재사용하고 기능을 잃지 않게 |
| `app/api/artworks/[id]/image/route.ts` | 그림 썸네일/완성 이미지. 인증된 학생 요청 흐름 유지 |
| `app/api/storybooks/route.ts` | 책 목록 `id`, `title`, `pageCount`, `status`, 날짜 제공. **표지 썸네일은 현재 목록 응답에 없음** |
| `app/components/StorybookLibrary.tsx` | 기존 전체 책 목록 `/student/books` |

권장 이동: 그림 0장 → `/student/draw/new?mode=free`; 1장 이상 → 새 그림 자리(`/student`에서 표시하거나 별도 내부 경로). 새 그림 카드 → `/student/draw/new?mode=free`; 진행 중 그림 → `/student/draw/{id}`; 완성 그림 → `/student/archive/{id}`; 내 그림 모두 보기 → `/student/archive`; 책 → `/student/books/{id}`; 내 그림책 모두 보기 → `/student/books`. 기존 그림 보관함과 그림책 편집기는 이번 시안에 맞춘다고 삭제하지 않는다.

책 표지는 가능한 경우 실제 저장된 표지로 채운다. 현재 책 목록 API에는 표지 URL이 없으므로 구현 시 별도 미리보기 경로/응답을 검토하거나 우선 빈 책 틀에 DOM 제목을 표시한다. 목록 조회 때 책마다 무거운 문서·이미지를 한꺼번에 받는 방식은 피한다.

## 반응형·접근성

- 시안의 1536×1024는 방향 기준이다. 390px에서 그림 네 장을 억지로 한 줄에 줄이지 않는다. 좁은 화면은 제목 → 새 그림 그리기 → 내 그림 → 내 그림책 순으로 보이고, 가로 목록을 쓴다면 스크롤·초점·끝 카드가 잘리지 않게 한다.
- 320×568, 390×844, 844×390, 1440×1000에서 실제 DOM 크기·가로 넘침·연속 탭을 확인한다. 모든 터치 행동 최소 44×44px, 주 행동 56px 권장.
- 모서리 장식은 `alt=""`, `aria-hidden="true"`, `pointer-events:none`이고 본문 뒤에 놓는다. 좁은 화면에서 숨기거나 줄여도 정보는 온전해야 한다.
- 카드 전체가 링크라면 안쪽에 또 링크/버튼을 중첩하지 않는다. 진행 중/완성 상태는 색만으로 구분하지 않고 글자로 적는다. 키보드 초점도 보여 준다.
- 종이 질감은 카드 바탕에만 희미하게. 업로드된 아이 작품에는 필터·반투명 오버레이·강제 자르기를 얹지 않는다.
- 많은 그림/책은 일부만 보여 주고 기존 전체 목록으로 이동한다. 처음 로딩/오류/책 0권 상태도 만든다.

## 디자인 수치

`tokens.css`는 **이 화면 전용 제안값**이다. 저장소의 `docs/bmad/planning-artifacts/ux-designs/ux-wiggle-web-2026-08-31/DESIGN.md`가 기본 시각 규칙이다. 시안의 따뜻한 크림 책상은 국소 바탕으로만 쓰고 다른 화면의 전역 토큰을 바꾸지 않는다. 폰트는 저장소의 Pretendard 계열을 재사용한다.

## 검수와 범위

- 웹용 WebP 5종은 PNG 원본에서 `cwebp`로 인코딩했고 투명 컷아웃 4종의 알파 최소값 0, 네 모서리 알파 0을 확인했다. `desk-surface`는 불투명한 배경이 맞다.
- 생성 장식에는 글자·아이 그림·버튼이 없다. 메모지도 비워 두었다.
- `manifest.json`에 모든 파일의 치수·바이트·SHA-256이 있다. `PROVENANCE.md`에 ImageGen 프롬프트와 출처를 적었다.
- 현재 코드 기준 `typecheck`, 린트(오류 0·기존 경고 14), production build 포함 `npm test` **397/397** 통과. 테스트는 지원 Node 24 + `NODE_OPTIONS=--dns-result-order=ipv4first`로 로컬 HTTP 하네스를 실행했다. 에셋 파일의 SVG XML과 PNG/WebP 디코딩도 확인했다.
- 에셋 전달만 완료했다. 화면 구현·실제 기기 검증·PR·운영 배포는 하지 않았다.

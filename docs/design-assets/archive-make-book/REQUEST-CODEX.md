# 보관함에서 여러 그림 골라 그림책 만들기 — 시안 요청서 (코덱스용)

> 작성: 2026-09-23 · 요청자: Wiggle Web
> 받고 싶은 것: **화면 시안 2안**(+ 필요한 아이콘/장식 에셋). 코드는 우리가 쓴다.

## 0. 한 줄 요약

아이가 그림을 완성하면 **보관함**(`/student/archive`)에 도착한다. 여기서 **그림 여러 장을 골라
그 그림들로 그림책을 한 번에 만드는 길**을 새로 낸다. 지금은 한 장씩만 넣을 수 있다.

## 1. 사용자

- **초등학교 3~6학년.** 읽기 수준 차이가 커서, 핵심 행동은 글자 없이 **그림과 큰 터치 목표**로도
  이해돼야 한다. 안내 문구는 짧은 한국어 한 줄.
- 교실 태블릿·노트북. 손가락 입력이 기본이고 마우스도 있다.
- **터치 목표는 최소 44×44px.**

## 2. 지금 화면 (바꾸기 전)

`/student/archive` — **펼친 스케치북** 한 권이 화면 가운데 있다.

- 왼쪽 쪽: 완성한 그림 목록(작은 썸네일 세로 목록). 누르면 오른쪽에 펼쳐진다.
- 오른쪽 쪽: 고른 그림 한 장이 크게. 아래에 `‹ ›` 넘기기 단추와 「이 그림 열기」.
- 머리: `📖 그림책`(그림책 목록으로), `📕 수업 마치기`.
- 페이지를 넘길 때 **책장이 3D로 넘어가는 연출**이 있다.
- **760px 미만에서는 책 그림을 쓰지 않고** 한 장 레이아웃으로 바뀐다(목록은 가로로 밀어 고른다).

첨부:

- `current-archive-narrow.png` (390×844) — **지금 깨져 있습니다.** 오른쪽이 잘려 나갑니다.
- `current-archive-narrow-partial-fix.png` — 깨짐 원인 하나를 임시로 막고 찍은 것. 머리는 제대로

> 머리(로고·그림책·수업 마치기) → 제목 → **가로로 미는 썸네일 줄** → 고른 그림 큰 카드 → 아래 단추.

## 3. 풀어야 할 문제

보관함은 **"한 장을 크게 펼쳐 보는"** 화면이다. 여기에 **여러 장 고르기**를 얹으면 두 성격이 부딪힌다.

- 상시 체크박스를 깔면 → 평소에 그림 감상이 방해된다. 아이가 실수로 고르기도 한다.
- 고르기를 너무 숨기면 → 기능이 있는 줄 모른다.

**이 긴장을 어떻게 푸는지가 이번 시안의 핵심이다.**

## 4. 시안 2안을 주세요

### 안 A — "그림책 만들기"를 누르면 고르기 모드로 들어간다

- 평소 보관함은 지금 그대로(감상 우선).
- 머리의 `📖 그림책` 옆(또는 아래)에 **「그림책 만들기」**를 둔다.
- 누르면 **고르기 모드**: 목록의 썸네일마다 고르기 표시가 생기고, 아래에 「N장 골랐어요 · 그림책 만들기」 띠가 붙는다.
- 「취소」로 평소 화면으로 돌아온다.

### 안 B — 목록에서 바로 고를 수 있다

- 썸네일을 **길게 누르거나 모서리 표시를 누르면** 고르기가 시작되고, 그때부터 탭이 곧 고르기다.
- 한 장이라도 고르면 아래 띠가 **올라온다**.
- 아무것도 안 골랐으면 평소와 똑같다.

두 안 모두 아래를 보여 주세요.

1. **평소 상태** (아무것도 고르지 않음)
2. **3장 고른 상태** — 고른 표시가 어떻게 보이는지, **몇 번째로 골랐는지(쪽 순서)** 가 보이는지
3. **좁은 화면**(390×844)에서 같은 상태
4. 고른 뒤 누르는 **확인 화면**(3-3 참고)

## 5. 꼭 담아야 할 것

- **쪽 순서.** 고른 순서가 그대로 책의 쪽이 된다. 아이가 "내가 2번째로 골랐네"를 알 수 있어야 한다.
  (순서를 나중에 바꾸는 건 그림책 편집기에서 한다 — 여기서는 안 다룬다.)
- **책 모양 고르기.** 가로 / 세로 / 정사각 세 가지가 있다. 지금은 `/student/books`에서 먼저 고르는데,
  이 흐름에서는 **언제 고르는 게 자연스러운지 제안**해 주세요(고른 뒤 확인 화면에서? 미리?).
  기본값 추천은 **가로**(이야기책).
- **0장일 때.** 아직 아무것도 안 골랐으면 「그림책 만들기」가 어떤 모습인지(흐리게? 안내 문구?).
- **완성작만 고를 수 있다.** 그리는 중인 그림은 못 넣는다 — 목록에 섞여 있을 때 어떻게 구분하는지.
- **많이 고를 때.** 20장을 고르면 어떻게 보이는지(띠에 숫자만? 작은 줄?).

## 6. 하지 말 것

- **그림책 편집기(`/student/books/[id]`)는 이번 범위가 아니다.** 만든 뒤에는 기존 편집기로 간다.
- 아이 **실명·점수·순위·별점**을 넣지 않는다. 우리 제품에는 그런 게 없다.
- 그림을 대신 배치해 주거나 "이 그림이 좋아요" 같은 **평가·추천을 넣지 않는다.**
- 시안 전체를 배경 이미지 한 장으로 만들지 말 것 — **글자와 누를 것은 우리가 DOM으로 만든다.**
  배경/장식만 이미지로 받는다.

## 8. 받는 형식

- 시안 이미지 **PNG**, 폭 1400px 이상. 안별로 폴더를 나눠 주세요 (`option-a/`, `option-b/`).
- 새로 필요한 **아이콘·장식**은 투명 배경 PNG로 따로. 크기와 쓰임을 파일 이름이나 메모로.
- 짧은 **설명 메모**(`notes.md`): 왜 그렇게 풀었는지, 고른 표시를 왜 그 모양으로 했는지.
- 두 안의 **차이를 한 줄로** 정리해 주면 고르기 쉽다.
